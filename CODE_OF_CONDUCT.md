# Code of Conduct

emberpost adopts the **Contributor Covenant v2.1** verbatim as its code of conduct. The full text is at:

<https://www.contributor-covenant.org/version/2/1/code_of_conduct/>

It applies to all project spaces: this repository (issues, pull requests, discussions, code review), any official chat channels, and project events.

## Reporting

Report concerns privately through a
[GitHub private report](https://github.com/shubhamkatta/emberpost/security/advisories/new).
Reports are read by the project owner only and handled per the Covenant's "Enforcement Guidelines". We acknowledge within 72 hours and work toward a resolution within 30 days.

Do not post conduct concerns in public issues or pull requests. Use the private route above.

## Scope summary

- **Be respectful, patient and constructive.** Assume good intent. Give specific, actionable feedback.
- **Welcome newcomers.** Every maintainer was a first-time contributor once. Onboarding questions are not noise.
- **No harassment, personal attacks or discriminatory language.** Not in issues, PRs, commits, code comments or anywhere else in project spaces.
- **Respect maintainer time.** Search before asking, provide minimal reproductions for bugs, and align on design before coding a large feature.
- **Keep reports safe to share.** Redact passwords, API keys, webhook URLs and real email addresses before pasting logs or configs.

Maintainers may, at their discretion, remove comments, close issues, revert commits or block accounts that violate these standards.
